# YNAB Budget Assistant

Connect your financial life to [YNAB](https://www.ynab.com/) via the YNAB API. This project handles:

1. **Amazon transaction enrichment** -- match Amazon credit card transactions with actual item descriptions and categories
2. **AI-powered categorization** -- categorize ambiguous transactions using Claude (with a token-efficient tiered approach)
3. **Spending insights** -- surface spending anomalies, trends, and over-budget categories

## Prerequisites

- [uv](https://docs.astral.sh/uv/) for Python dependency management
- [Node.js / npm](https://nodejs.org/) for development scripts (linting, quality checks)

## Setup

1. Install dependencies:
   ```bash
   uv sync
   npm install
   ```
2. Generate a YNAB API token at <https://app.ynab.com/settings/developer>
3. Copy `.env.example` to `.env` and add your token:
   ```bash
   cp .env.example .env
   # Edit .env and set YNAB_API_TOKEN="your_token_here"
   ```
4. Run `uv run python setup.py` to fetch and cache your budget ID, account IDs, and category list
5. This writes a local `config.json` -- **do not commit this file or `.env`**

## Usage

### Enrich Amazon Transactions

```bash
uv run python amazon_matcher.py --input data/imports/amazon_orders.csv
```

Matches Amazon order history to YNAB transactions by date and amount, assigns categories via Claude, and writes item descriptions to the transaction memo field. **Requires your review before writing anything back to YNAB.**

### Categorize Uncategorized Transactions

```bash
uv run python categorizer.py --days 30
```

Fetches uncategorized transactions from the last N days and suggests categories using a three-tier approach:

1. **History lookup** -- payees seen before resolve from a local cache (free)
2. **Fuzzy match** -- catches payee name variations like store numbers (free)
3. **Claude (Haiku, batched)** -- only genuinely novel payees, batched into one API call

Presents suggestions for review before writing back.

### Spending Insights

```bash
uv run python insights.py --months 3
```

- Summarizes spending by category over the last N months
- Flags categories over budget
- Detects anomalous transactions (statistical outliers within each category)
- Shows month-over-month trends

## Conventions

- **Human review required** -- no writes to YNAB without confirmation
- **API rate limit** -- YNAB allows 200 requests/hour; batch where possible
- **Amounts** -- YNAB uses milliunits (1000 = $1.00); conversion happens at the boundary
- **Dates** -- ISO 8601 (YYYY-MM-DD) internally
- **Caching** -- API responses cached in `data/cache/` to avoid redundant calls

## Testing

This project follows strict test-driven development. Tests use static fixtures in `data/fixtures/` and never hit real APIs.

```bash
uv run pytest tests/ -v                  # run all tests
uv run pytest tests/test_categorizer.py  # run one module
uv run pytest tests/ --cov              # with coverage report
```

### Coverage Targets

| Module | Target | Rationale |
|---|---|---|
| `ynab_client.py` | >90% | Touches real money |
| `amazon_matcher.py` | >90% | Touches real money |
| `categorizer.py` | >85% | Core categorization logic |
| `insights.py` | >80% | Read-only, lower risk |

## Open Decision: Amazon Order History Source

Personal Amazon accounts no longer support CSV export. Options under consideration:

1. **Amazon Order History Reporter (Firefox extension)** -- fast CSV output, but requires trusting a third-party extension
2. **Amazon "Request My Data"** -- official, but takes 3-5 days and produces JSON
3. **Skip item-level enrichment** -- route all Amazon charges to a single category via payee history

Decision needed before implementing `amazon_matcher.py`. See [CLAUDE_project-spec.md](CLAUDE_project-spec.md) for full trade-off analysis.
